# Quits OSS v0.16.3

Changes since the published v0.16.2 tag (`45d51f59`), through `2d1d7c77` (#456). This patch release covers 4 merged PRs in the self-hostable Quits core.

## Invoices and credit notes

- English invoices, credit notes and their PDFs now say "No VAT" and "25 % VAT" on the lines. Before, they said "No moms" and "25 % moms". Danish documents are unchanged (#454).
- The invoice and credit note pages now show the buyer's tax numbers, such as "CVR-nr. 24256790", under "Fakturer til", as the PDF already did. An issued document shows the numbers it was issued with (#456).
- On a new invoice, the amounts show "—" until the organization's currency has loaded. Before, they could briefly show "0,00 US$" (#455).

## E-invoices

- When an issued invoice has no e-invoice (UBL), the download panel now explains why as soon as it opens, without a click, and hides the download button that could not work (#454).

## Customer picker

- Looking up a company by CVR number in the customer picker no longer stays on "Søger i CVR-registret …". A cancelled search clears, and a search with no answer after 15 seconds ends with the usual "try again" error (#455).

## Settings

- The invoice and credit-note prefixes must stay apart. Settings now warns as you type when the two prefixes are equal and disables Save. The server also refuses a prefix change if the new prefix already starts a number in the other series, for example a credit-note prefix of `FAK` after invoices moved from `FAK` to `INV`. This keeps credit note numbers from repeating invoice numbers. Prefixes that are not changed are never checked, so other settings always save (#457).

## Upgrading

The workspace, app, contracts and shared package versions move together. Package manifests are the version authority. There are no database migrations and no configuration changes, and the contracts and shared packages are unchanged apart from their version.

- New tRPC query `exports.einvoiceStatus({ kind, id })`. It returns `null` for a draft, `{ stored: true }` when an e-invoice is stored, and otherwise `{ stored: false, missing }`. It is additive; `exports.einvoice` is unchanged (#454).
- `sellerVatLineLabel` is now a deprecated alias of `sellerVatLineText`. Registered 25 % lines read "25 % VAT" in English (#454).
- `invoices.get` gains a `buyerTaxIds` field (#456).
- `settings.update` can now refuse a prefix change with the existing `document_prefix_conflict` error when the changed prefix is already used by the other series (#457). Seeds or scripts that set invoice and credit-note prefixes must keep them distinct.

This release does not configure or deploy any hosted service.
