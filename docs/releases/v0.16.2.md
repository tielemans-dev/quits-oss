# Quits OSS v0.16.2

Changes since the published v0.16.1 tag (`8f423f64`), through `6e97f7fd` (#451). This patch release covers 2 merged PRs in the self-hostable Quits core.

## E-invoices

- A Danish seller who is not VAT-registered now gets an e-invoice (UBL) when issuing. Before, these invoices were issued without one. The lines and VAT breakdown use category E (exempt) at 0 %, with an exemption reason that cites momsloven § 71 e in the document language. The seller's CVR is sent as the legal registration (BT-30) and as the tax registration identifier (BT-32, scheme `TAX`). No seller VAT ID (BT-31) is sent. Invoices from VAT-registered sellers are unchanged (#451).
- When an issued invoice has no e-invoice, the download panel explains why and lists the details that were missing when it was issued, in the interface language. An e-invoice can never be added to an issued invoice afterwards (#451).

## Loading after a deploy

- During a deploy, a page could get its HTML from the old version and then fail to load that version's files, and stay on "Indlæser…" until reloaded by hand. A small script in the page head now reloads the page when one of its own `/assets/` files fails to load before the app has started. It retries after 1, 2, 5 and 10 seconds and then stops. Once the app has started it never reloads, so unsaved input is not lost (#452).

## Upgrading

The workspace, app, contracts and shared package versions move together. Package manifests are the version authority. There are no database migrations and no configuration changes.

- `einvoiceMissingFieldSchema` gains `document.vatUnclassified`, and the failed e-invoice export result gains an optional `issued` flag. Both are additive (#451).
- Runtimes that render or check e-invoices should expect a UBL for sellers who are not VAT-registered, with category E and a `TAX` seller scheme (#451).
- The root document now has a second inline head script, next to the theme script. A Content-Security-Policy that allows inline scripts by nonce or hash must also allow this one (#452).

This release does not configure or deploy any hosted service.
