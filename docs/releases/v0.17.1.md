# Quits OSS v0.17.1

Changes since the published v0.17.0 tag (`2669f444`), through `80dbfcf8` (#468). This patch release covers 1 merged PR in the self-hostable Quits core.

## Customers

- "Opdater fra CVR" on the customer page now says what happened. It shows "Opdateret fra CVR-registret." when the register changed the customer, or "Kunden er allerede opdateret. Intet er ændret i CVR-registret." when nothing changed (English: "Updated from the CVR register." / "Already up to date. Nothing has changed in the CVR register."). The page shows the refreshed customer straight away, without waiting for a refetch. A failed refresh still shows the lookup's message and clears any earlier notice (#468).
- Creating a customer from the standalone new customer form now opens that customer's page instead of the customer list. Creating a customer from a new invoice still returns to the invoice with the customer selected (#468).

## Invoices

- The live preview on a new invoice now shows the full buyer block: the name, a distinct company name, the tax numbers such as "CVR-nr. 24256790", the email and the billing address. It matches the "Fakturer til" block on the saved draft, and both now come from the same component. The email tab still shows only the recipient's name and email (#468).

## Upgrading

The workspace, app, contracts and shared package versions move together. Package manifests are the version authority. There are no database migrations and no configuration changes, and the contracts and shared packages are unchanged apart from their version.

- `buildBuyerSnapshot` now lives in the effect-free `lib/documents/buyer-snapshot.ts`, so client code can use it. It is still exported from `domain/documents/snapshots.ts` and behaves as before (#468).

This release does not configure or deploy any hosted service.
