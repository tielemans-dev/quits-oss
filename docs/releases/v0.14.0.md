# Quits OSS v0.14.0

Changes since the published v0.13.0 tag (`3b939f25`), through `393954b1`. This minor release covers 36 merged PRs in the self-hostable Quits core.

## Organization access (breaking runtime contract)

The billing provider now returns `BillingSubscription.organizationAccess`, the server's access decision: `self_hosted`, `trial` with server-calculated days left, `subscribed`, `complimentary`, or `read_only` with reason `trial_ended`, `payment_failed` or `canceled`. The core write guard, banner, form gates and billing page all use this one decision. A missing decision refuses writes and shows the organization as read-only (#343).

Providers must also return the `access` billing capabilities explicitly, including `checkoutAvailable` and `portalAvailable`. The trial hook now runs on every successful onboarding, including registry outages, with `cvrVerified: false` for a pending identity. Later verification calls the hook again with `cvrVerified: true` and must keep the original trial window. See [organization access](../architecture/organization-access.md).

Self-hosters using the noop provider keep unlimited access with no hosted gates. Runtimes with their own billing provider must return the decision before upgrading.

## Managed sending domains

Expected managed sending-domain rejections return safe, localized client errors. Runtime providers throw the exported `ManagedDomainRejectedError` with reason `invalid_domain`, `not_found` or `conflict`; unexpected failures remain server errors (#340).

## Command palette and Overblik

- Grow the command palette out of the top-bar search field, then make the Overblik field the palette itself, unfolding into cards as it is typed (#354, #355, #357, #374, #376).
- Complete half-typed requests from invoices and customers, start a request card's reads while it is typed, offer every reading of a request as a card, and ask in place for what a request left out (#360, #361, #362, #363, #366, #367, #373, #377).
- Optionally read whole sentences with a decision model. It is off unless the operator sets `QUITS_TYPESAFE_API_KEY`, and the organization's AI draft setting still applies. Only the kind of request is asked; customers are matched in the app (#364, #365).
- Lead Overblik with what needs attention, and send the overdue card to email settings when email is not set up (#358, #380).

## App style

Establish shared light and dark restyle tokens, a new app shell, sidebar and top bar, and Settings split into pages with their own sidebar and row-style company profile. Share the skeleton fill while Settings load, and conform motion to the 300ms spatial cap with reduced-motion fades (#341, #349, #350, #351, #352, #353, #356).

## Reliability

- Centralize frontend query refresh dependencies so document lists, details, Settings and financial panels refresh after changes, distinguish query failures, and persist supply dates before review (#344, #345, #346, #347).
- Report whether email delivery is configured through the runtime capabilities, refuse email jobs without delivery configuration, and stop a stuck reminder job's toast from returning on every page (#371, #372).
- Run scheduler ticks during local development (#375).

## Tooling

Adopt the Vite+ toolchain: Vite 8 with Rolldown, `vp` tasks in place of Turbo, `vp lint` and `vp test`. The published `nitro` dependency is pinned to an exact nightly instead of `latest`. Align seller VAT test evidence with current legal wording, and let browser readiness retry slow Nitro startup (#342, #348, #359).

## Upgrading

The workspace, app, contracts and shared package versions move together. Package manifests are the version authority. This release adds no database migrations.

Runtimes that supply their own billing provider must return `organizationAccess` and the `access` capabilities for every organization, and handle trial hooks with `cvrVerified: false`, before serving this release. Otherwise every organization becomes read-only. This release does not configure or deploy any hosted service.
