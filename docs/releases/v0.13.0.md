# Quits OSS v0.13.0

Changes since the published v0.12.4 tag (`733e6c1e`), through `3b8f77e6`. This minor release covers 39 merged PRs in the self-hostable Quits core.

## VAT reporting periods

Enter manual purchase VAT for a reporting period alongside the period overview and TastSelv summary export (#301). Documents now include seller SE numbers and the Danish VAT basis for exempt and reverse-charge supplies (#315, #326).

## Accounting integrations

- Prepare e-conomic and Dinero invoice and credit-note payloads from frozen financial evidence (#306, #307).
- Persist encrypted connections, schedule delivery through injectable transports, and manage accounting connections and account and VAT mappings in Settings (#310, #311, #313, #324).
- Audit disconnect and failed-delivery actions, guard reconnect and sync starts, and verify delivery totals and frozen evidence before sending (#316, #320, #323, #329, #330).

Live provider authorization, connect flows and production transport remain follow-up work. Self-hosters can supply the runtime adapters without hosted gates. See [accounting integrations](../accounting-integrations.md) for supported events, refusal conditions and transport requirements.

## Agreement templates

Built-in fixed-price and milestone agreement templates use Danish or English names and terms according to the organization's language. Untouched built-in templates follow language changes; customized terms remain unchanged (#322).

## App and document improvements

- Add an eight-second Fortryd undo action to command-bar toasts, persist repeat-invoice send actions and delay seller payment emails during the undo window (#290, #302).
- Show previously silent workflow failures, form validation summaries and focus links (#304, #321).
- Correct public quote amounts and recurring invoice validation (#318).
- Improve accessible labels, focus and empty states, mobile overflow, select controls, invoice detail lines and draft row actions (#314, #317, #328, #337).
- Align app, email and onboarding colors and spacing with the design scales, and finish shared motion timings (#309, #334).
- Show the onboarding Stripe step only when payments are enabled (#336).

## Verification and tooling

Repair typecheck, test and browser CI fixtures, separate Playwright suites from Vitest, and add nightly visual, accessibility and design reports. Vendor pinned framework references and check documentation versions in CI (#298, #300, #303, #305, #308, #319, #325, #327, #331, #332, #333, #335, #338).

## Upgrading

The workspace, app, contracts and shared package versions move together. Package manifests are the version authority. Apply all seven new database migrations through the normal migration path before serving the updated app:

- `20261015210000_manual_purchase_vat`
- `20261015230000_accounting_delivery_retry`
- `20261016000000_accounting_connection`
- `20261016010000_accounting_safeguards`
- `20261020000000_accounting_sync_position`
- `20261021000000_accounting_mappings`
- `20261022000000_seller_se_number`

Configure the existing `BETTER_AUTH_SECRET` and runtime adapters before using accounting connections. Existing issued financial evidence stays frozen. This release does not configure or deploy any hosted service.
