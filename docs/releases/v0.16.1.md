# Quits OSS v0.16.1

Changes since the published v0.16.0 tag (`8422d650`), through `ac51f4db` (#449). This patch release covers 4 merged PRs in the self-hostable Quits core.

## Customers and CVR lookup

- On the new-customer form, a second CVR lookup replaces the name the first lookup filled in. A name someone typed or edited still survives a lookup (#447).
- When the CVR lookup finds a company that is not active, the form still fills, but the hint becomes a warning that names the status and its date, for example "CVR-status: Konkurs pr. 14. maj 2001. Tjek, at det er den rigtige kunde." The status names match onboarding's (#448).

## Invoices

- When sending fails because the customer is missing details, each error names the missing field, such as "Tilføj kundens adresse", instead of a generic "Udfyld feltet". The invoice page links to editing the customer (#449).
- A blank new invoice no longer warns about an unsupported currency before the organization's settings have loaded. The readiness check waits for the organization's own currency. The web manifest is fetched with credentials, so an access proxy no longer redirects it (#446).

## Upgrading

The workspace, app, contracts and shared package versions move together. Package manifests are the version authority. There are no database migrations and no configuration changes.

- `invoiceIssueKey(code, field?)` takes an optional field argument. Callers that do not pass it behave as before (#449).
- `useOrgCurrencyState()` is new and reports whether the currency came from loaded settings. `useOrgCurrency()` is unchanged (#446).

This release does not configure or deploy any hosted service.
